# Bank Customer Transaction & Suspicious Activity Analysis

## Project Overview

This project analyzes banking transaction data to understand transaction patterns and identify suspicious and fraudulent activity.

The project follows an end-to-end data analytics workflow using Python, SQL, and Power BI.

## Objectives

- Clean and prepare banking transaction data.
- Perform exploratory data analysis.
- Analyze transaction and fraud patterns using SQL.
- Identify high-value and late-night suspicious transactions.
- Build an interactive Power BI dashboard.
- Present the findings in a clear and understandable way.

## Dataset

The dataset contains approximately 550,000 banking transaction records with information related to:

- Customer and transaction details
- Transaction amount and account balance
- Transaction type and direction
- Merchant category
- State
- Transaction status
- Channel
- KYC status
- Loan information
- Fraud indicator
- Transaction hour

A small sample dataset is included in this repository for reference.

## Python Analysis

Python was used to:

- Inspect and clean the dataset.
- Handle missing values.
- Analyze transaction patterns.
- Explore transaction amounts, balances, status and fraud.
- Create data visualizations.
- Export the cleaned dataset.

## SQL Analysis

SQL was used to analyze:

- Transaction counts and distributions.
- Fraud by transaction type.
- Fraud by channel.
- Fraud by merchant category.
- Fraudulent activity by transaction hour.
- High-value transactions.
- High-value fraudulent transactions.
- Late-night fraudulent transactions.

## Power BI Dashboard

The Power BI dashboard contains:

### Transaction Overview

- Key transaction KPIs
- Transaction patterns
- Channel analysis
- Status analysis
- Transaction type and direction analysis

### Fraud & Suspicious Activity

- Fraud analysis
- High-value transactions
- High-value fraudulent transactions
- Late-night fraud
- Fraud patterns by channel, merchant category and transaction hour

## Key Findings

- The dataset contains a large volume of banking transactions.
- Fraud represents a relatively small portion of total transactions.
- Fraud patterns vary across channels, merchant categories, transaction types and transaction hours.
- High-value transactions provide an additional category for monitoring.
- Late-night fraudulent transactions can be separately monitored as suspicious activity.

## Conclusion

This project demonstrates an end-to-end data analytics workflow.

Python was used for data cleaning and exploratory analysis, SQL was used for structured transaction and fraud analysis, and Power BI was used to create interactive dashboards.

The project provided practical experience in combining multiple data analytics tools to analyze and present real-world-style banking transaction data.
